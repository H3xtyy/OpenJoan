# src/interfac

Engine code of joan.exe (original `d:\ww\interfac\`): the interface screens and widgets (barracks, shop, workshop,
letters, SMS, object menus, the options menu, combo boxes, lists). One file per original source file, named after it
(`re/attribution.csv`); every function keeps its registration (name, module key, address). Functions of this
directory not attributed yet still sit in `src/game/unknown_*.cpp`.

| File | Original |
|---|---|
| `i_barr.cpp`, `i_buy.cpp`, `i_work.cpp`, `i_letter.cpp`, `i_sms.cpp` | the facility and message screens |
| `objmenu.cpp`, `objmenub.cpp`, `objmenuw.cpp` | object menus |
| `optmenui.cpp` | the OPTIONS screen (`OptMenu`) |
| `mouse_options.{hpp,cpp}` | `[Fixes] MouseOptions`: the camera slider's lower range and the cursor sensitivity slider |
| `combobox.cpp`, `list.cpp`, `minires.cpp` | widgets and the mini resource set |

OpenJoan additions (not in the original, behind settings): `graphics_page.*` (a GRAPHICS OPTIONS page on the options
menu and the `openjoan.ini` rows of VIDEO OPTIONS), `remap_set.*` (keyboard / gamepad control sets of the key bindings
page), `joystick_option.hpp` (the options menu's joystick control when a pad is plugged in or out), `view_range.hpp`
(draw distance sliders widened from the original's range).

The function table below is generated from the registrations (`python3 tools/module_table.py src/interfac --write`).

Verification: objcmp (`tools/objcmp-x86.sh`) for moves and renames, a manual play test
 for the screens, the replay for game state.

See also: [`src/game/README.md`](../game/README.md), [`src/original/README.md`](../original/README.md) (typed layouts).
