# src/enphysic

Engine code of joan.exe: physics (rigid bodies, collision tests, the physics system), curated out of `src/game/_unplaced` in Phase 3. joan.exe has no `__FILE__`
string for these files; the file names follow the Restaurant Empire 2 engine symbols (`re/re2_engine_matches.csv`),
whose engine kept them in `enphysic/` (in joan's 2004 tree the code sat between the uti3d objects). One file per original
source file; every function keeps its registration (name, module key, address).

The function table below is generated from the registrations (`python3 tools/module_table.py src/enphysic --write`).
