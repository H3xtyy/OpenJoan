# src/elib

Engine code of joan.exe (original `d:\ww\elib\`): the one original file there is `jpeg.cpp`, the game's glue to the JPEG
library (the library itself is `src/lib/jpeg`). The file is named after the original (`re/attribution.csv`) and every
function keeps its registration (name, module key, address).

The function table below is generated from the registrations (`python3 tools/module_table.py src/elib --write`).

Verified by the 32-bit objcmp reference build for moves and renames (`tools/objcmp-x86.sh`) and by a manual play test
.

See also: [`src/lib/jpeg/README.md`](../lib/jpeg/README.md), [`src/ilib/README.md`](../ilib/README.md).
