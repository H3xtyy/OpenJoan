# src/platform

The platform layer: what joan.exe asked Windows for (USER32, KERNEL32, WINMM, ...) answered on SDL3 and portable C++.
Anything that calls the OS directly belongs here or in the loader (`docs/CONTRIBUTING.md` section 5). No registrations: these are
import overrides (`src/runtime/loader/import_overrides.hpp`), not game functions.

| Area | Files |
|---|---|
| Window, input, time (SDL3) | `window.hpp`, `sdl_window.cpp` (window, message pump), `sdl_input.cpp` + `input.hpp` (keyboard, mouse, gamepad), `sdl_time.cpp` (`timeGetTime`, performance counter, sleeps), `sdl_internal.hpp` |
| Files | `files.{hpp,cpp}` (the game folder with case-insensitive names, files in memory with `[Platform] FilesInMemory`, the KERNEL32 file imports) |
| Settings | `ini.{hpp,cpp}` (`openjoan.ini` without the Windows profile API) |
| Memory and faults | `memory.{hpp,cpp}` (page protection, virtual memory, fault handlers used by the stray guard and the crash handler) |
| Process and system | `process.cpp`, `threads.hpp`, `system.cpp` (critical sections, process / thread / event imports) |
| Text | `text.{hpp,cpp}`, `text_tables.inc`, `text_case.inc` (code pages and locale; the two `.inc` are generated), `dbcs.{hpp,cpp}` (double-byte code pages and the CJK font for localised editions) |
| Types | `win32_types.hpp`: the Win32 vocabulary (`DWORD`, `HRESULT`, `RECT`, ...) the ported code keeps using |
| Window icon | `openjoan_icon.inc`, generated by `tools/make_icon.py`, do not edit |

Settings read here: `[Platform]` `Gamepad`, `PadAutoInput`, `PadCameraInvert`, `PadMenu`, `PadCurve`, `CodePage`,
`CjkFont` (and the others of that section in `src/openjoan.ini`, whose comments are the reference).

Verification: a manual play test; the replay recorder wraps this layer's
inputs ([`src/runtime/replay`](../runtime/replay/README.md)).

See also: [`docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md) section 6,
the CJK notes in `src/en2d/README.md`.
