# src/lib/jpeg

The game's IJG libjpeg 6b compressor (joan.exe 0x007a9a60..0x007b1540) and the D3DX8 parts it uses (`jcomapi`, `jerror`),
typed in `jpeglib.hpp`. The game uses it to write screenshots; each `.cpp` names the original library sources it covers
(`re/attribution.csv`, `lib/jpeg/...`).

| File | What |
|---|---|
| `compress_api.cpp` | the compression API, parameters, destination manager |
| `compress_core.cpp` | main controller, colour conversion, coefficient controller, memory manager, master control |
| `compress_entropy.cpp` | forward DCT, Huffman and progressive entropy coders, marker writer |
| `jpeg_crt.{hpp,cpp}` | what the compressor uses of the game CRT and of D3DX8's data (the 120 error strings are our copy, equal to the original's table at 0x9e1c68) |
| `jpeglib.hpp` | typed declarations |

The function table below is generated from the registrations (`python3 tools/module_table.py src/lib/jpeg --write`).

Verification: the smoke checklist (screenshot key); objcmp for moves. The JPEG file glue of the game is
[`src/elib/jpeg.cpp`](../../elib/README.md).

See also: [`src/lib/README.md`](../README.md).
