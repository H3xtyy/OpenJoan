# src/lib/crt

The MSVC 6 C runtime joan.exe linked, ported. Each `.cpp` begins with a comment listing the original library sources it
covers (`re/attribution.csv` `original_file`, under `lib/crt/...`); several original files share one of ours. The game
calls these functions by their original addresses (registered like game functions, so the call graph is unchanged);
`crt.hpp` gives direct C++ entry points for game code that called the CRT by address.

| Area | Files |
|---|---|
| Heap | `heap.cpp` (malloc / free / new handler; the deterministic heap `runtime/det_heap` and the guard heap sit behind it) |
| stdio and low-level I/O | `stdio.cpp`, `lowio.cpp`, `ioinfo.hpp`, on `platform/files` |
| Formatting and parsing | `printf.cpp` (`_output`, float output), `scanf.cpp` (`_input`, `_fltin`), `string_format.cpp`, `xtoa_misc.cpp`, `varargs.hpp` |
| Strings and memory | `string.cpp`, `mem_intrinsics.cpp`, `search_rounding.cpp`, `wide_string*.cpp`, `mbstring.cpp`, `ctype.cpp`, `qsort_vc6.hpp` (the VC6 qsort as a template; the comparison sequence is part of behaviour, cf.) |
| Locale and time | `locale.cpp`, `time.cpp` |
| Threads | `mt.cpp` (`_tiddata`, locks) |
| Start-up, exit, exceptions | `startup.cpp` (`WinMainCRTStartup` 0x007b71e6), `exit.cpp`, `eh_support.cpp`, `seh_unwind.cpp` |
| x87 maths | `x87_math.cpp`, with `fp/pc53.hpp` and `fp/x87_64.hpp` for the exact results |
| Notes only | `wcslwr_fcvt_notes.cpp` (nothing registered) |

The function table below is generated from the registrations (`python3 tools/module_table.py src/lib/crt --write`).

Hazards: the CRT is where 32-bit `FILE` / ioinfo / `_tiddata` shapes live; the 64-bit counts are tracked by
`tools/x64_hazards.py`. Verification: objcmp for moves, the replay (a CRT difference changes game state), the smoke
checklist; strings and tables compared with the original's at the 2026-11-08 review.

See also: [`src/lib/README.md`](../README.md), [`src/fp/README.md`](../../fp/README.md),
[`docs/ARCHITECTURE.md`](../../../docs/ARCHITECTURE.md) section 6.
