# src/lib/imports

`import_stubs.cpp`: small imports of joan.exe (and a few CRT / D3DX leftovers: `_strdup`, validation, the unhandled
exception filter) implemented in C++ on the platform layer, registered like game functions. Larger import families are
in [`src/platform`](../../platform/README.md); which import is answered by what is decided by
`src/runtime/loader/import_overrides.hpp`, and the unanswered ones trap (`dead_imports.inc`).

The function table below is generated from the registrations (`python3 tools/module_table.py src/lib/imports --write`).

Verification: a manual play test; the import census (`[Debug]` in
`openjoan.ini`, `src/runtime/import_census.*`) lists imports reached at run time.
