Generated by `python3 tools/scan_formats.py $JOAN_WORK_DIR/game --md …` over a full copy of the install. The tool can also emit the first bytes
of the smallest file per extension; that part is not kept here because the pages quote no file contents. Regenerate the census table after any
change to the tool; keep the notes by hand.

`CreateUnit`, `.wav` = a 38-byte `CreateWa…` stub, not RIFF audio) next to binary `.pfd .map .gri .pln .nod`; 824 `.pro` of which 819 are
`VERSION`-headed model property files beside `.smo` (different from the 5 `Resource/*.pro` day-cycle profiles); `.bmp`/`.tga` source textures
still shipped (`texture/misc`, `int8x6/item`); `.mda` ×17, `.amt` ×16, `.ma` ×15 (grass/flag animation side files); `.res` ×67 (28 of the 29
under `script/scenario` start with the string id `[0001N]`).

## Sample headers observed
- `.fin`: `"GoudyOlSt BT"` + zero pad to 32 B, then `20 00 FF 00 0E 00 0D 00 10 00 03 00 E0 00 00 00 ...` (u16 first_char=0x20, u16 count=0xFF, height 14, ..., then per-glyph u16 widths).
- `.nvo`: `4E 56 46 4F 14 00 00 00` ("NVFO", 0x14) … fragment names `NVFNtransform_and_write_position`.
- `.pso`: `00 01 FF FF` (ps.1.0 version token) … `FF FF 00 00` end token.
- `unitAI.res`: `12 00 00 00` (18 records) then `char[0x20] name` + `u32 offset` (`HUMAN_LIGHT_GENERAL`, `PIG`, `HUMAN_ARCHER`…).
- `Gameplay.res`: `06 00` + 6 × (`char[9] name`, `u32 offset`): ECON, THROWI, UNIT, CHARMOVE, WEATHER, GAME → text sections.
- `Resource/Resource`: `14 00` + 20 × (`name\0` padded, `u32 offset`): HEADER, ANIMATE, SDATE, DEFAULT, AMAZON1, MODEL, RACE, ITEM…
- `Cursor.res`: `03 67 05 03 02 00 00 00 A1 00 13 00 …` then field descriptors `HFILENAME\0\0C…`, `HHOTSPOT_X\0N…` (type letter + name + width).
- `t_basic.txr`: two count lines (`37`, `38`) then `KEY|n` lines.
- `.cm`, `.bm`, `.lgt`, `.sca`, `.pro`, `.scr`: plain `Key: value` / `Block { key:value; }` text.
- Text encoding for this install: **Windows-1250** (Polish).
