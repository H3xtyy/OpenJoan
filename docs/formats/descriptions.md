# `des/*.txt` and `item_des/*.txt` - descriptions

Plain text files (INVENTORY: 25 under `des/`, 81 under `item_des/`) holding the descriptions shown for siege weapons, strategic tips and items.
They are not particle scripts: `script/pscript/*.txt` ([pscript.md](pscript.md)) has the same extension and is a different grammar.
No structured format is known; the files are read as text by the description screens.
